# iOS 科研情报 App 构建计划

## 产品定位

构建一个 iOS 原生科研情报 App，面向需要持续跟踪神经科学、生物材料、AI、骨科等方向的用户。系统每天自动抓取论文、预印本、技术资讯和机构动态，经过主题筛选、去重、质量排序和大模型中文精炼后，生成可快速阅读的每日简报，并通过推送提醒用户。

## MVP 范围

- iOS 原生 App 首页展示今日简报。
- 内置四个主题：神经科学、生物材料、AI、骨科。
- 每个主题支持开启或关闭订阅。
- 每天自动抓取 PubMed、bioRxiv、medRxiv、arXiv 和主流资讯源。
- 每条内容生成中文精炼卡片。
- 支持收藏、已读、原文跳转。
- 支持每日推送通知。
- 支持基础搜索和按主题筛选。

## 核心流水线

1. 定时调度任务启动每日采集。
2. 各数据源连接器按主题查询新内容。
3. 将不同来源的数据标准化为统一文章模型。
4. 根据 DOI、PubMed ID、标题相似度去重。
5. 用主题规则和语义相似度进行归类。
6. 给每条内容计算质量分和相关性分。
7. 对高分内容调用大模型生成中文摘要。
8. 将结构化摘要、元数据和来源链接写入数据库。
9. 生成用户级每日简报。
10. 触发 APNs 推送通知。

## 中文摘要模板

- 一句话结论
- 研究问题
- 方法亮点
- 核心发现
- 潜在价值
- 局限性
- 适合人群
- 原文链接

## 推荐技术栈

- 客户端：SwiftUI、URLSession、UserNotifications。
- 后端：FastAPI、PostgreSQL、pgvector、Redis、Celery 或 RQ。
- 摘要：OpenAI、Claude、Gemini 或兼容 OpenAI 协议的模型。
- 推送：Apple Push Notification service。
