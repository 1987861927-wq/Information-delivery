# iOS App

SwiftUI iOS App 代码骨架。可以在 Xcode 中新建 iOS App 项目后，将 `ResearchIntelApp/ResearchIntelApp` 下的源码加入项目。

## 主要页面

- 今日简报
- 主题切换
- 搜索
- 收藏
- 我的/推送设置

## 后续任务

- 在 Xcode 中创建正式 `.xcodeproj`。
- 配置 Bundle Identifier。
- 接入 APNs Capability。
- 将 API Base URL 指向 FastAPI 服务。
